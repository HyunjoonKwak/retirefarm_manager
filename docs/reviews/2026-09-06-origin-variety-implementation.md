# 산지 연동 품종 필터 구현

범위: 산지·기간·단위에 따른 품종 선택지와 거래 확인 표시. Codex가 API·집계·서버 테스트, Claude가 필터 화면·요청 상태·UI 테스트를 담당한다.

## 데이터 계약

`GET /api/market/garak?action=facets&productName=…&days=30&origin=…&unit=…`

- 로그인 필수. 품목 필수, 조회 기간 1~730일. 잘못된 기간은 400으로 응답한다.
- 선택된 품종은 집계 조건에서 제외해 다른 품종을 추가 선택할 수 있게 한다.
- 전체 품종 후보, 해당 산지의 마지막 거래일, 해당 산지·기간의 품종/단위별 행 수를 그룹 집계한다. 원본 거래 전체를 클라이언트에 전달하지 않는다.
- `available`: 현재 산지·기간·단위에서 저장된 거래 있음.
- `filtered_out`: 해당 산지·기간에는 거래가 있으나 선택 단위 결과 없음.
- `no_period_records`: 해당 산지의 보관 중인 과거 기록만 있음.
- `unobserved`: 해당 산지에서 보관 중인 기록 미확인. 생산·출하가 없다는 뜻이 아니다.
- `originPeriodCount`와 `matchingCount`는 저장된 거래 행 수다. 수집된 전체 시장 물량이나 농가 수가 아니다.
- `collectionState=stored_records_only`로 반환한다. 기존 수집 로그에 부분 수집 누락 문제가 남아 있으므로 완전 수집을 보증하지 않는다. DB 실패는 500이며 정상 0건으로 바꾸지 않는다.

## 화면 동작과 교차 검토

- 산지·단위 선택기를 품종 앞에 배치. 기본은 거래 확인 품종과 기존 선택만, 전체 보기에서 나머지를 이유와 함께 탐색할 수 있다.
- 산지를 바꿔 조회 결과가 없어진 기존 선택도 유지하며 단위 해제·기간 확장을 제공한다. 숨은 품종으로 검색 조건을 자동 교체하지 않는다.
- 선택은 체크와 채움, 거래 확인은 건수와 점, 기록 미확인은 별도 문구로 구분한다. 전체 보기의 사유는 모바일에서도 읽을 수 있도록 본문에 표시한다.
- 선택된 단위·산지는 현재 목록에 없더라도 남겨 해제할 수 있다.
- 품종 후보·시세·일별 상세·품종/산지 목록 요청에 취소 및 요청 식별 가드를 적용했다. A→B→A, 같은 키 재요청에서도 예전 응답과 로딩 해제를 차단한다.
- 조건 갱신 중 이전 품종의 거래 확인 강조를 제거하고, 시세·상세 새 요청 시 예전 결과를 비운다. 마지막 거래일의 UTC 날짜 절단으로 인한 하루 밀림을 보완했다.
- `asOf`는 선택지 조회 시각이며 실제 데이터 수집 시각이 아니다. 화면도 ‘조회’ 시각으로 구분한다.

## 이번 구현의 한계

기존 차트·일별 상세와 일치하도록 산지의 문자열 부분 일치 규칙을 유지한다. 표준 지역 코드·상하위 지역 사전, 등급 필터, 수집 완전성 개선, 품종별 중앙값·분포 분석은 기존 로드맵의 후속 범위다. 현재 history의 로컬 날짜 기준 조회 구간도 유지한다. 이 기능만으로 실제 생산·실시간 출하 상태를 판정하지 않는다.

DB 스키마 변경은 없다. 운영 데이터 수집·마이그레이션·배포는 이 구현 작업에 포함하지 않는다.

## 검증 결과

- 최종 전체 테스트: 21개 파일, 151개 테스트 통과. 기존 115개에서 서버 13개, UI/계산/요청 가드 23개 추가.
- 전체 타입 검사와 프로덕션 빌드 통과. 빌드는 스케줄러 초기화를 막는 기존 `NEXT_PHASE=phase-production-build` 설정으로 실행.
- 전체 ESLint: 오류 0, 기존 경고 28. 마지막 보완 후 변경 파일 ESLint 오류·경고 0.
- `git diff --check` 통과.
- API 테스트는 로그인·입력·오류 전파를, 서비스 테스트는 집계 응답 모형으로 조건·상태·건수를 검증한다. UI는 jsdom/React Testing Library 기반이며 실제 로그인 브라우저·운영 시세 E2E와 시각 검수는 수행하지 않았다.

Claude의 최초 구현 이후 Codex가 로딩 중 이전 산지 강조 제거, 동일 키 재요청 가드, 목록 요청 가드, 날짜 표시 및 본문 설명을 교차 보완했다. 품종별 분포 분석 전체가 구현된 것은 아니며 이번 완료 범위는 산지 연동 선택 UI와 해당 조회 API다.
