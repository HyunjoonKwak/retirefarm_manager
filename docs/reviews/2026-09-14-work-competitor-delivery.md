# Work 보고서·경쟁점 가격 연계

> 2026-09-14 정정: 공식 쇼핑검색 API는 2026-07-31 종료됐다. 아래 어댑터는 구현·배포 이력이며 현재 사용할 수 있는 검색 기능이 아니다. 키 신규 발급 안내를 철회한다. [브라우저 수집 검토·대체 계획](2026-09-14-browser-competitor-collection-plan.md)을 따른다.

## 구현

- `/reports`에 Work 보관함과 경쟁점 조사 탭을 추가했다.
- Work Markdown/JSON의 미리보기, 사용자별 원문 보존, 중복 방지, 원본과 정정본 연결을 제공한다. 정정은 새 레코드이며 기존 내용을 바꾸지 않는다. 형식이 맞지 않는 JSON도 원문으로 보관하고 통계로 승격하지 않는다.
- 실제 공유 화면의 observation v1은 `sources`가 이름별 URL 객체다. 이를 지원하며 날짜 중복·등급 열 불일치·비정상 범위는 집계를 보류한다. 공개 일평균의 주간 단순평균과 원거래 수량 가중평균은 별도 출처·지표다.
- 네이버 공식 쇼핑검색 API만 호출한다. 서버 전용 키, 1회 100건·유사도순, 12초 제한, 응답 1MiB 제한, 리다이렉트 거부. 사용자당 5분 간격·24시간 20회 예약 제한, 같은 검색 재사용, 실패도 호출 예산에 포함한다.
- 검색 결과는 후보다. API 순서를 비광고 순위로 표시하지 않는다. 제목 중량은 제안이며 복수 중량·묶음은 확인 필요, 최저가 0은 미확인이다. 스테비아·가공품은 제외 추정으로 분리한다.
- 고정 비교군 최대 30개 점포. 실제 스마트스토어 상품 URL, 품목·품종군·품질군·옵션·중량을 직접 확인해야 등록된다. 점포 중복을 막고 교체 시 보관 사유와 관측 이력을 유지한다.
- 재고·상품가·배송비·실제 관측시각을 기록한다. 배송비 공란은 미확인, 0은 무료다. 현재 7일 이내 확인한 동일 조건의 서로 다른 3개 점포 이상에서만 배송 포함 중앙값·범위를 표시한다. 전주 변화는 7일 전 기준에도 관측된 동일 고정 옵션끼리 비교한다.
- 브리핑 미리보기와 생성 입력에 실제 확인 지표만 반영한다. 경쟁점은 생성 시각 기준 최신 참고 자료임을 표시한다. Work는 보고 종료일이 가장 최근인 보관본(동일 종료일 최신 저장본)에서 보고 주간에 해당하는 자료만 참조한다. 숫자 없는 원문은 보관 사실만 표시한다.
- 원가 계산기는 생산원가·포장비·수수료 입력 전 계산하지 않는다. 배송비 3,500원·목표마진 15%는 수정 가능한 기존 Work 가정이다. 다른 중량과의 가격 차이는 보류한다. 판매가 자동 변경은 없다.

## 실제 자료 확인

사용자가 제공한 공유 URL의 2026-09-14 오전 11시 정정 보고서와 JSON을 화면에서 읽었다. 다운로드 바이트 원본이 아닌 화면 전사본으로 경위를 명시했다. 대추방울 3kg 7일, 일반 방울 5kg 13일 관측, 3개 출처가 정규화되었다. 9/7~13 일반 방울 특품 단순평균 44,114.3333원/5kg는 공유 보고서 정정 값과 일치한다. 실제 스마트스토어 확인 0곳을 그대로 보존한다.

## 네이버 키 확인 결과와 설정

`store_manager` 로컬 환경 및 운영 컨테이너에 공식 쇼핑검색 키가 없었다. 해당 프로젝트는 별도 검색 프록시를 사용하며 API Hub/커머스 설정은 쇼핑검색 키와 다르다. 설정 DB의 기존 주소를 로컬·운영에서 조회했으나 404였다. 비밀값은 로그에 출력하지 않았다.

**설정 안내 철회:** 공식 쇼핑검색 API 종료로 키를 추가해도 대안이 되지 않는다. 기존 설정과 어댑터는 배포 이력으로 남아 있으며, 종료 안내 UI와 검색 호출 중단 처리는 후속 구현 대상이다. 수동 관측·Work 보관은 별도로 사용 가능하다.

## 후속 개발 순서

1. 종료된 검색 경로 정리, 브라우저의 선택 옵션 가격 추출·검토 도구 구현, 크기·등급 구분 후 고정 비교군 30곳 기준선 확보.
2. Work 과거 전문 추가 이전 및 보고서별 명시적 근거 선택. 현재 자동 선택은 최근 종료일 보관본 한 건이다.
3. 재배·기상·정책·물류 공식 소스의 공지 수집, 게시일·확인일·원문 근거·정정 이력과 '확인했으나 새 내용 없음/수집 실패' 구분. 현재 이 분야 최신 사실 자동 수집은 미구현이다.
4. 월요일 10시 KST 예약과 Mac 실행 누락 복구. 기존 ChatGPT 예약은 아직 이전되지 않았다.
5. 텔레그램 봇·수신처 등록 후 중복 전송 방지/전송 결과 불명 상태를 포함한 알림 연결. 현재 자동 예약과 전송은 OFF다.
6. 장기 가격 이력 보존·백필 운영, 경쟁점 4주 추세는 실제 관측이 쌓인 뒤 제공. 과거 가격을 역산해 채우지 않는다.
