# 경쟁 상품 수집 확장과 실자료 검증

## 범위

첫 버전의 화면 텍스트 붙여넣기를 Chrome 확장의 자료 복사·파일 가져오기로 확장한다. 확장은 현재 상품 페이지에서 사용자가 버튼을 눌렀을 때만 읽는다. 서버 전송·로그인 정보 접근·자동 저장·주기적 방문은 제공하지 않는다. 운영 앱에는 ZIP 다운로드와 설치·사용 안내를 제공한다.

Claude가 확장 소스·패키징·테스트를 담당하고 Codex가 실제 판매처 조사, 앱의 수집 자료 검증·입력·수집 시각 보존, 통합 검증과 배포를 담당했다.

## 발견한 파서 문제와 수정

- 실제 DOM 텍스트는 `총 금액 → 도움말 → 16,400원` 구조다. 기존 바로 다음 줄만 읽는 규칙은 놓칠 수 있어 정확한 ‘도움말’ 한 줄만 건너뛰도록 했다. 쿠폰 등 임의의 중간 문장은 건너뛰지 않는다.
- 선택 옵션은 `상품명 → 옵션명 → 옵션 가격`으로 표시됐다. 이 구조와 `총 1개`를 지원한다. `총 2개` 등은 단일 옵션 가격으로 확정하지 않는다.
- 세 상품의 실제 제목 주변 가격 영역 innerText를 테스트 자료로 보존하고 수동으로 확인한 옵션·금액과 대조한다. 전체 페이지·리뷰 본문·추적 쿼리는 자료에 넣지 않는다.
- 이 표본은 가격 영역의 표시값과 파서 검증이다. 배송 조건이 다른 영역에 있으면 자동으로 발견했다고 간주하지 않으며, 저장 전 일반 배송비와 지역 추가운임을 사람이 확인한다.

## 가져오기 계약

확장 자료 형식은 `retirefarm-visible-product-v1`: productUrl, capturedAt, title, text, method(selection/product-region). 앱은 엄격한 형식 검사 후 같은 상품 주소인지 확인한다. 호스트·판매자·상품 번호를 대조하고 추적 쿼리는 제거한다. 다른 상품·미래 시각·24시간 초과 자료는 거부한다. JSON 자료는 40,000자, 본문은 30,000자, 업로드 파일은 160,000bytes로 제한한다.

가져오기는 기록 폼을 채우는 작업이다. 선택 옵션명 일치, 수량 1·쿠폰 제외 확인, 재고 확인을 거쳐 별도 저장한다. 수집 시각의 초·밀리초를 보존하고, 사용자가 관측 시각을 직접 수정하면 수정값을 사용한다. 메모에는 파서 버전 `visible-page-v2`, 원래 수집 시각·상품 주소·추출값·주의사항을 남긴다.

## 사용자 설치와 다음 작업

앱의 ‘브라우저 수집 도구 설치·사용’에서 ZIP을 다운로드·압축 해제하고, Chrome `chrome://extensions`의 개발자 모드에서 압축 해제된 확장을 로드한다. 확장의 미리보기 후 JSON을 복사하거나 저장하여 해당 고정 패널로 가져온다. 사용자 브라우저에 자동 설치하거나 확장 권한을 변경하지 않았다.

남은 단계는 실제 설치 상태에서 팝업·복사·다운로드 흐름 검증, 동일 크기 기준을 확인한 판매처 패널 구축, 며칠간 반복 정확성 검증이다. 월요일 예약과 30곳 무인 방문은 아직 구현하지 않았으며, 접근 조건·차단 처리·Mac 가용성 검증 이후에 진행한다.
